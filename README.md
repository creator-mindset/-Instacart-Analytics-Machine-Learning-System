# 🛒 Instacart Analytics & Machine Learning System
![Instacart HQ](https://images.ctfassets.net/4rnblstkg79m/6eQtQFBIIiwCJjBK7d5fLA/4d35f9000b15c739999e32309cd30509/25_Instacart_HQ.jpg)
Performed large-scale data analysis and built machine learning models using the Instacart Market Basket Analysis dataset containing 3.4M+ orders, 200K+ users, and 49K+ products.

---

## 📌 Project Overview

This project focuses on analyzing customer purchasing behavior and building predictive machine learning models for business decision-making.

The project includes:

- Advanced SQL Business Analysis
- Customer Behavior Analytics
- Customer Segmentation using K-Means
- Product Reorder Prediction
- Next Order Prediction
- Interactive Streamlit Dashboard

## 🤖 Machine Learning Models

### Random Forest Regressor

Predicts the expected number of days until the customer's next order.

Target Variable:

- days_since_prior_order

---

### Random Forest Classifier

Predicts whether a customer is likely to reorder a product.

Target Variable:

- reordered

---

### K-Means Clustering

Segments customers into different purchasing behavior groups using:

- Total Orders
- Total Products
- Average Cart Position
- Average Days Between Orders
- Total Reorders
